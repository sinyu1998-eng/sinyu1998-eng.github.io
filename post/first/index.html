万物法则：让每个人都能在外贸里，找到一个角色
这是「万物法则」的第一篇。不谈融资，不喊口号，只讲清楚我们是谁、要做什么，以及为什么这件事和你有关。

先说清楚两件事，免得你误会。

第一，公司叫「万物法则」。 它的法律主体是浙江青釉轩雅服饰有限责任公司——2025 年 2 月 20 日在义乌成立，注册资本壹仟万元。做服饰批零起家，如今把方向定在一件事上：用一套系统，把中国货和想买中国货的人，重新连起来。

第二，公司和个人是两件事，但连着。 我是黄倩如，你也可以叫我小黄。这个公众号发公司的事；我个人的经历、研究和创作，放在另一个地方。两者会因为同一个人而相互参照，但账要分开算、事要分开讲。这是「万物法则」的第一条规矩：角色要清楚，边界要清楚。

起因：先找市场，再谈产品

我最认可的一套创业方法，第一步不是做产品，是市场细分——把目标缩小到最有前景的 6~12 个市场，针对每一个去做实地调查，和客户当面聊。

我在义乌做这件事。见过做收纳用品的工厂老板，货堆在仓库，老客户下单越来越碎，新客户在哪根本摸不着；也接触过几百家工厂和贸易公司，跨境出海卡住的地方翻来覆去就是那几件事：库存是死钱、跟单靠人脑、找不到终端买家。

但义乌真正厉害的，不是小商品本身，而是它让每一个人都能在这门生意里承担一个角色、互相联系。有人做货，有人跑单，有人拉客，有人报关，有人送货——谁都不用一个人干完全部，谁都能凭自己那一段赚到钱。

这就是我选中的市场：不是卖货，是把"人—货—客—钱"的连接，做成一张能自动运转的网。

唯一重要的检验标准：有没有人愿意付钱

创业方法里有一句我抄在本子上的话：

企业成功的唯一充分必要条件，是付费客户。不是产品、技术、愿景、团队，也不是资金和投资者——那些都重要，但都不是答案。业务直到有人愿意掏钱买，才算真的成立。

这句话很残酷，也很清醒。它让我们把力气用在刀刃上：

  • 不做"看起来很美"的功能，先问谁会为它付钱；
  • 不堆人、不堆概念，先跑通一笔真实订单；
  • 每个人在这张网里的角色，最终都要落到他能不能分到钱。

所以「万物法则」做的不是软件展示品。是一套能让角色各司其职、让订单闭环、让钱算得清的系统。

我们做的事：把这张角色网络，做成软件

SellerPilot 不是一个只给公司用的工具。它是一张角色网络：

  • 你是工厂，系统把你的货挂到海外买家面前，来询盘先算清 CIF 保本价，再谈报价；
  • 你是外贸员，九段状态机替你盯节点，六项成本账本替你记明细，异常才提醒你介入；
  • 你是海外买家，在一个官网上看中国货、看中国行，注册一个账号就把你和工厂、货代接成一条工作流；
  • 你是导游 / 地接，带老外来中国看市场——旅游是获客，注册是入网，你带来的每个人都是网络里的新角色；
  • 你是货代、海外仓、主播、验货员、商会、开发者……这张网里都有你能站的位置。

我们做了一个页面，把这套角色讲清楚了：每个人都能在这里找到自己的位置。你可以按身份筛，点开看每个角色做什么、系统怎么帮你、收益从哪来、怎么加入。

用客户的角度想问题：工厂要的是不压价、有订单；买家要的是货真、能验、能到；每个角色要的，都是"我这一段，能分到多少"。系统围着这些转，而不是围着我们的想象转。

说实话：我们现在还小

我们人很少。所以必须讲清楚哪些是真的、哪些还在做：

已经能跑的：SellerPilot OS 的九段外贸状态机、CIF 保本报价、六项成本账本、异常预警——一套可运行的软件，把角色网络里的重复活自动化。代码在 GitHub 上能看到。

已有的入口：对外官网 margueritesbury.com，带老外做 sourcing，也了解来中国旅游。

正在整合的：Singles Way（老外来中国旅游、注册当角色）、AI 视觉识别（参考 DeepLab / YOLO 做看图认货、验货）、直播 / 货代 / 海外仓 / 商会 / 政府关系这些资源方——这些是我们要整合好的方向，不是已经上线的承诺。

我们不打算靠堆人把这件事做起来。靠的是：状态机干重复活，先把钱算清，异常才需要人，资源用接的不用买的。

从今天起，这张网开始找人

一张网，从一个人的一个角色开始。
