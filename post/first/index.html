我们注册公司了：让每个人都能在外贸里，找到一个角色
这是「杭州青袖科技」的第一篇。不谈融资，不喊口号，只讲清楚我们是谁、要做什么，以及为什么这件事和你有关。

这周，我们把公司注册下来了。

杭州青袖科技有限公司，2026 年 11 月 24 日成立，注册在杭州余杭。经营范围里写着软件开发、人工智能应用、互联网销售，还有服装服饰、化妆品、日用百货的批发零售——这几行字，其实是我们接下来要做的事的缩影：用一套系统，把中国货和想买中国货的人，重新连起来。

起因：义乌给我的启发

我在义乌待过一段时间，见过做收纳用品的工厂老板，货堆在仓库，老客户下单越来越碎，新客户在哪根本摸不着。

也接触过几百家工厂和贸易公司。跨境出海卡住的地方，翻来覆去就是那几件事：库存是死钱、跟单靠人脑、找不到终端买家。

但义乌真正厉害的，不是小商品本身，而是它让每一个人都能在这门生意里承担一个角色、互相联系。有人做货，有人跑单，有人拉客，有人报关，有人送货——谁都不用一个人干完全部，谁都能凭自己那一段赚到钱。

这件事，今天还主要靠微信群、人情和运气在维系。我们想把它搬进一个系统。

我们要做的事：把这张角色网络，做成软件

SellerPilot 不是一个只给公司用的工具。它是一张角色网络：

  • 你是工厂，系统把你的货挂到海外买家面前，来询盘先算清 CIF 保本价，再谈报价；
  • 你是外贸员，九段状态机替你盯节点，六项成本账本替你记明细，异常才提醒你介入；
  • 你是海外买家，在一个官网上看中国货、看中国行，注册一个账号就把你和工厂、货代接成一条工作流；
  • 你是导游 / 地接，带老外来中国看市场——旅游是获客，注册是入网，你带来的每个人都是网络里的新角色；
  • 你是货代、海外仓、主播、验货员、商会、开发者……这张网里都有你能站的位置。

我们做了一个页面，把这套角色讲清楚了：每个人都能在这里找到自己的位置。你可以按身份筛，点开看每个角色做什么、系统怎么帮你、收益从哪来、怎么加入。

一句话：义乌靠人和人的联系把生意做起来，我们想让这套联系，被系统记住、被系统放大。

说实话：我们现在还小

我们人很少。所以必须讲清楚哪些是真的、哪些还在做：

已经能跑的：SellerPilot OS 的九段外贸状态机、CIF 保本报价、六项成本账本、异常预警——一套可运行的软件，把角色网络里的重复活自动化。代码在 GitHub 上能看到。

已有的入口：对外官网 margueritesbury.com，带老外做 sourcing，也了解来中国旅游。

正在整合的：Singles Way（老外来中国旅游、注册当角色）、AI 视觉识别（参考 DeepLab / YOLO 做看图认货、验货）、直播 / 货代 / 海外仓 / 商会 / 政府关系这些资源方——这些是我们要整合好的方向，不是已经上线的承诺。

我们不打算靠堆人把这件事做起来。靠的是：状态机干重复活，先把钱算清，异常才需要人，资源用接的不用买的。

为什么是我们

这不是凭空想出来的模式。

我从国内电商做到跨境电商，带团队管过 90+ 店铺，上一年度自有体系约 1 亿元 GMV；从义乌的田野，到浙江大学的工科训练，再到德州农工、亚利桑那州立大学，一路把一线踩过的坑，做成了这套系统里的每一步。

系统里的每个节点，都先在真实订单里跑过，才写进代码。

从今天起，这张网开始找人

如果你——

  • 有工厂、有货源，想直接接到海外订单；
  • 懂外语、会直播、能带团、做货代、开海外仓；
  • 做支付、做软件、做商会、做园区，想把这些能力接进一张真实的交易网络；
  • 或者只是想来中国看看货、看看市场——

你都能在这张网里找到一个角色。

点开角色页，选一个你能承担的，看看系统怎么帮你。也可以直接把你的角色、城市和资源发给我们，我们帮你定位你在网络里的位置。

一张网，从一个人的一个角色开始。
