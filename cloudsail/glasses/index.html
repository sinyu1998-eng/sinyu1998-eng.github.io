现状解剖你手上这套东西是什么

先把家底说清楚——你的系统其实已经是「眼镜 → 手机 → 云」三段式，缺的只是最后一段的接入。

LAYER 1 · 硬件

AiMB-G3 相机眼镜

  • 8MP 摄像头，1200p/30fps 录像
  • WiFi + 蓝牙，与手机配对
  • 镜腿触控：长按录像 / 双击拍照
  • 3 组可换镜片 · CE/RoHS · $199
  • 没有屏幕、没有开放 SDK
LAYER 2 · 手机 App

Cyan Glasses（青成白牌）

  • 配对、拍照录像回传、录音
  • 1对1 / 对话翻译、AI 语音问答
  • 媒体同步到手机相册
  • 会员 ¥38/月 · ¥298/年
  • 无企业模式、无 API、无导出接口
LAYER 3 · 缺口

到 CloudSail 的桥

  • 眼镜拍的内容停在手机相册，没进系统
  • 没有 VLM 视觉识别层
  • 没有工单号 / 时间水印
  • 没有证据哈希与报告产出
  • 这一页就是补这层缺口的方案

DAY 1–7

桥的原型

  • 手机桥 App/小程序：读相册 → 打工单号 → 上传

三条红线不能省的合规动作

01 · 知情

被拍摄方同意

  • 录制时 LED 必亮（硬件已有，别关）
  • 工厂与员工签拍摄知情书
  • 客户来访验货单独授权
02 · 数据

不出境

  • VLM 只调国内模型（千问/豆包/智谱）
  • 照片存国内 OSS，客户可索取副本
  • 30 天后原片可删，保留哈希
03 · 事实

识别不夸大

  • 报告里标注「AI 初判 + 人工复核」
  • NG 判定必须有人工确认入口
  • 准确率数据按周公示给工厂
