三步就能用

  1. 点上面的按钮，文件会下载到你的「下载」文件夹。
  2. 双击 CloudSail-Desktop.html，用浏览器打开（Chrome / Edge / Safari 都行）。
  3. 开始用。关掉浏览器再打开，数据还在。
手机上也能用：下载后点文件 →「用其他应用打开」→ 选浏览器。电脑上体验更完整。

里面是什么

报价 / 毛利按真实外贸成本结构算：采购、国内杂费、FOB/CIF、海运、保险、关税、退税、佣金、汇率。给出建议售价、实际毛利率、盈亏平衡价，外加 7 种波动情景的敏感性。每一步计算都列出来，能拿计算器复核。
客户 · 商品 · 订单真实增删改，本地保存。订单从待审批开始，必须人工批准才推进。
审批与留痕每步操作写进审计链，带前序哈希；能一键校验完整性，也能模拟篡改看它能不能发现。
交付物生成报价单、询盘跟进邮件（中英）、周度经营简报、交付验收清单。可下载 .md，也可直接打印成 PDF。
项目归位把散在 63 个目录里的东西按「感知 / 运营 / 决策 / 结算 / 交付 / 主体合规 / 归档」归到一条线上，可搜索、可改处置、可导出清单。
导入 / 导出客户、商品、订单、审计日志都能导 CSV（Excel 直接打开）；全量数据可导出/导入 JSON 备份。

它不做什么

  • 不联网、不上传、不收集数据——你可以断网后照常用。
  • 不自动替客户发消息。需要人确认的地方就停在那里，等人批。
  • 内置的几条客户和订单是示例数据，用来验证功能，可在「导入 / 导出」里一键清空。
