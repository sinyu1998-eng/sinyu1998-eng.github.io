三步就能用

  1. 点上面的按钮，文件下载到「下载」文件夹。
  2. 双击 CloudSail-Console.html，用浏览器打开（Chrome / Edge / Safari 都行）。
  3. 直接开始用。关掉浏览器再打开，数据还在。
手机上也能用：下载后点文件 →「用其他应用打开」→ 选浏览器。左侧图标栏可切换模块，卡片单列排列。

面板上每一块是什么

引擎 · 运行状态报价计算实测耗时（微秒）、单笔报价金额区间、审批响应时长、报价毛利率区间。
业务 · 订单链路客户与国家数、订单总额与单均、待办审批、交付完成率。
系统 · 完整性审计链条数与校验状态、资产归位、数据记录总数、计算引擎采样。
能力矩阵感知 / 运营 / 决策 / 结算 / 交付 / 主体合规 / 归档，7 层各自的目录数与文件数。
报价 / 毛利引擎按真实外贸成本算：采购、国内杂费、FOB/CIF、海运、保险、关税、退税、佣金、汇率。给出售价、实际毛利率、盈亏平衡价 + 7 种波动敏感性，每步可核对。
审批与留痕订单必须在这里人工批准才推进；每步写入审计链，带前序哈希，可校验、可模拟篡改检测。
交付物生成报价单、询盘跟进邮件（中英）、周度简报、验收清单，可下载 .md 或打印 PDF，内容取自你的真实数据。
导入 / 导出客户、商品、订单、审计日志导 CSV（Excel 直接开）；全量 JSON 备份可还原。

它不做什么

  • 不联网、不上传、不收集数据——断网照常用。
  • 不自动替客户发消息。需要人判断的地方就停在那里，等人批。
  • 内置的几条客户 / 报价 / 订单是示例数据，用来验证功能，可在「导入 / 导出」里一键清空。
